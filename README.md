# QR Code Wallpaper Generator

A simple web application that generates beautiful iPhone wallpapers with QR codes.

## Features

- Generate QR code wallpapers sized perfectly for iPhone (1320 x 2868 pixels)
- Customizable URL for the QR code
- Add custom text below the QR code
- Choose your own background and text colors
- Download the generated wallpaper as PNG
- Clean, modern user interface

## How to Use

1. Open `index.html` in your web browser
2. Enter the URL you want the QR code to redirect to
3. (Optional) Add text to display below the QR code
4. (Optional) Customize the background and text colors
5. Click "Generate Wallpaper"
6. Preview your wallpaper
7. Click "Download Wallpaper" to save it to your device

## Setting as iPhone Wallpaper

1. Download the generated wallpaper
2. Transfer it to your iPhone (via AirDrop, iCloud, email, etc.)
3. Open the image in Photos app
4. Tap the share button
5. Select "Use as Wallpaper"
6. Position and set as Lock Screen, Home Screen, or both

## Technical Details

- **Canvas API**: Used for generating the high-resolution wallpaper
- **QRCode.js**: Library for generating QR codes
- **Responsive Design**: Works on desktop and mobile browsers
- **No Backend Required**: Everything runs in the browser

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `app.js` - JavaScript logic for QR code generation and wallpaper creation

## Browser Compatibility

Works in all modern browsers that support HTML5 Canvas API:
- Chrome/Edge
- Firefox
- Safari
- Opera
